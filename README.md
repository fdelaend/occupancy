# Code and data accompanying the manuscript

This repository contains the code and data required to reproduce the theoretical, simulation-based, and empirical results presented in the manuscript.

Computationally intensive model simulations and Bayesian models have already been run, and their outputs are included in the repository. Reproducing the analyses and figures therefore does **not** require rerunning these computations.

## Repository structure

The repository is organized as follows:

```text
/
├── code/               R and Python code used for simulations and analyses
├── daphnid-data/       Data and saved statistical models for the empirical Daphnid analyses
├── simulated-data/     Saved output from the model simulations
└── figures/            Figures generated by the analysis scripts
```

All code files are located in `code/`. The scripts use relative paths and should therefore be run with `code/` as the working directory.

## Reproducing the manuscript results

The code is designed so that computationally intensive analyses do not need to be repeated when their output is already available. Where relevant, the analysis scripts first check whether a previously saved result exists. If it does, the saved result is loaded; if it does not, the corresponding analysis is run and its output is saved.

With the complete repository downloaded, the manuscript figures can therefore be reproduced by opening R, setting the working directory to `code/`, and running:

```r
source("model-analysis.R")
source("model-analysis-daphnids.R")
source("daphnid-analysis.R")
source("model-simulations-d.R")
```

The scripts can also be opened and run section by section. They are organized using section headings that identify the different stages of the analyses and the figures being produced. This is useful for users interested in understanding or modifying a particular analysis.

The computationally intensive simulation scripts `model-simulations.R` and `model-simulations-daphnids.R` do **not** need to be run to reproduce the manuscript results. They only need to be consulted or run by users who specifically wish to regenerate the underlying simulation data from scratch.

## Analysis and figure-generation scripts

### `model-analysis.R`

Contains the main analyses of the theoretical model and the general model simulations. In particular, it evaluates the analytical results associated with Eqs. 8–13 and compares the analytical predictions with the simulation results.

Where computationally intensive intermediate calculations have previously been performed and saved, the script checks whether the corresponding output is available and uses the saved results rather than unnecessarily repeating the calculation.

Produces:

- Fig. 2
- Fig. 3
- Fig. S2
- Fig. S3

### `model-analysis-daphnids.R`

Analyses simulations of the model parameterized for the Daphnid system. The required simulation output is provided in `simulated-data/` and can therefore be analysed without rerunning the underlying simulations.

Produces:

- Fig. 7
- Fig. 8

### `daphnid-analysis.R`

Performs the empirical analyses of the Daphnid metacommunity data.

The Bayesian models used in the manuscript have already been fitted and their fitted objects are provided with the repository. The script checks whether these fitted models are available and loads them when present, rather than refitting them. If the saved model objects are absent, the corresponding models are fitted and their output is saved.

Produces:

- Fig. 4
- Fig. 5
- Fig. 6
- Fig. S1
- Fig. S5
- Fig. S6

### `model-simulations-d.R`

Runs simulations examining how mean population density across patches changes with dispersal rate. These simulations are used to assess the range of dispersal rates over which the effect of dispersal can be considered approximately linear.

Produces:

- Fig. S4

These simulations are relatively small and can be run on a standard computer. A computing cluster is not required.

## Regenerating the underlying simulation data

The following scripts are provided for users who wish to regenerate the underlying simulation datasets from scratch. **They do not need to be run, or inspected, to reproduce the manuscript analyses and figures**, because their simulation output is already provided in `simulated-data/`.

### `model-simulations.R`

Runs the general model simulations used to test the analytical predictions and their robustness when relaxing the assumptions of the analytical model.

These simulations are computationally intensive. We recommend running this script on a computing cluster if the simulation data are to be regenerated.

### `model-simulations-daphnids.R`

Runs the model simulations parameterized for the Daphnid system.

These simulations are also computationally intensive. We recommend running this script on a computing cluster if the Daphnid simulation data are to be regenerated.

### `job.sh`

SLURM job script used to run the computationally intensive simulations on a computing cluster.

This file is included only for users wishing to regenerate the simulation output. It is not required to reproduce the manuscript results from the saved output. Users running the simulations on another computing system will likely need to adapt the requested resources, paths, and other cluster-specific settings.

## Helper files

### `tools-simulations.R`

Contains functions used for the model simulations, including functions for constructing and simulating the metacommunity models.

This file is used by the relevant scripts and does not need to be run separately.

### `tools-other.R`

Contains functions used across the analysis scripts, including functions for the analytical calculations, empirical analyses, and figure generation.

This file is used by the relevant scripts and does not need to be run separately.

### `MVN.py`

Python code used to compute the cumulative distribution function of a multivariate normal distribution, as required for calculations involving the feasibility domain.

It is called from R through the analysis code and does not need to be run separately.

## Recommended workflow

For users wishing to reproduce the results reported in the manuscript, the recommended workflow is:

1. Clone or download the complete repository, retaining its directory structure.
2. Set `code/` as the R working directory.
3. Run `model-analysis.R` to reproduce the theoretical and general simulation results (Figs. 2, 3, S2, and S3).
4. Run `model-analysis-daphnids.R` to reproduce the Daphnid-specific simulation results (Figs. 7 and 8).
5. Run `daphnid-analysis.R` to reproduce the empirical Daphnid results (Figs. 4, 5, 6, S1, S5, and S6).
6. Run `model-simulations-d.R` to reproduce Fig. S4.

Equivalently, these four scripts can be sourced from R:

```r
source("model-analysis.R")
source("model-analysis-daphnids.R")
source("daphnid-analysis.R")
source("model-simulations-d.R")
```

The scripts automatically make use of saved results where applicable, so the computationally intensive analyses do not need to be repeated.

Users who want to understand individual analyses in more detail can instead open the corresponding script and proceed through its labelled sections step by step.

Users wishing only to reproduce the manuscript results can ignore `model-simulations.R`, `model-simulations-daphnids.R`, and `job.sh`. These files document how the underlying computationally intensive simulation datasets can be regenerated and are relevant only if those simulations are to be rerun from scratch.
